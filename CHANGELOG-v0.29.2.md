# Grey Ghost v0.29.2

## Realm Cooldowns

- Added `/cooldowns` and `?cooldowns`.
- The dashboard lists every personal action that uses a cooldown and shows **Ready** when it can be used immediately.
- Tracks `/daily claim`, `/daily train`, `/hunt go`, `/tavern dice`, `/tavern darts`, and `/tavern cups`.
- Lists daily `/stable train` readiness separately for every owned horse.
- Lists `/dragon feed`, `/dragon train`, `/dragon fly`, `/dragon patrol`, and `/dragon hunt` for a bonded dragon.
- Rolling cooldowns use Discord relative timestamps; UTC-day cooldowns show the next UTC reset when already used.
