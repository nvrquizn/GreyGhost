# Grey Ghost v0.29.1

## Welcome GIFs

- Added `/setup welcome-gif url:<link>` for Discord attachment/CDN and Tenor links.
- Added `/setup welcome-gif-clear`.
- Public welcome messages now place the configured GIF URL beneath the member welcome so Discord can render the media preview.
- `/testwelcome` uses the configured GIF.
- `/setup view` shows `Welcome GIF: Configured` without printing the stored URL.
- Clearing all basic server settings also clears the welcome GIF.
