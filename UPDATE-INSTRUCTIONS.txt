GREY GHOST v0.31.1 — STICKY MESSAGES — SAFE REPLACEMENT

1. Keep your existing live/local files and folders:
   - .env
   - data/
   - .git/
   - node_modules/
   - dist/

2. Replace the rest of your Grey-Ghost project with the contents of this folder.

3. In Terminal, from the Grey-Ghost project folder, run:
   npm install
   npm run commands:deploy
   npm run check

4. Make sure the event system is configured:
   /setup champions-role role:@Champions
   /setup tourney-summons role:@Tourney Summons
   /setup event-channel channel:#your-event-announcement-channel
   /setup event-chat channel:#your-event-chat

5. Optional: configure a welcome GIF:
   /setup welcome-gif url:<your-discord-or-tenor-link>

6. Configure and publish the new allegiance panels as needed:
   /selfroles configure panel:The Trial of Seven
   /selfroles configure panel:The Fossoway Apples
   Then use /selfroles emoji and /selfroles publish as normal.

7. If npm run check succeeds, commit and push:
   git add .
   git commit -m "Release Grey Ghost v0.31.1"
   git push

Railway should redeploy after the push.

IMPORTANT: do not replace your existing .env or data/ folder.


Sticky messages:
   /sticky set channel:#art message:<your rules or reminder>
   /sticky list
   /sticky remove channel:#art

Grey Ghost reposts configured sticky text after new member messages so it stays at the bottom of the channel.
