GREY GHOST v0.20.0 — SAFE REPLACEMENT

This folder intentionally excludes: .env, data/, .git/, node_modules/, and dist/.

1. Keep your current Grey-Ghost/.env and Grey-Ghost/data/ folder exactly where they are.
2. Replace the other project files/folders with the contents of this archive.
3. From the Grey-Ghost folder run:

   npm install
   npm run commands:deploy
   npm run check

4. If the check succeeds, commit and push:

   git add .
   git commit -m "Release Grey Ghost v0.20.0"
   git push

5. Railway will rebuild dist/ during deployment. Do not copy an old dist/ folder back in.
